# 期货季节性信号检测

每个交易日收盘后（北京时间 16:30）自动运行，检测以下品种的季节性入场信号：

| 品种 | 交易所 | 季节性逻辑 | 历史胜率 |
|------|--------|-----------|---------|
| 螺纹钢 | SHFE | 春节后复工需求 | 80% |
| 沥青 | SHFE | 冬季施工停工 | 80% |
| 铁矿石 | DCE | 钢厂冬储补库 | 82% |
| 鸡蛋(秋季空) | DCE | 中秋国庆后需求坍塌 | 85% |
| 鸡蛋(夏季多) | DCE | 高温减产+中秋备货 | 80% |
| 鸡蛋(春季空) | DCE | 春节后淡季去库 | 79% |
| 豆粕 | DCE | 美豆天气升水+饲料旺季 | 80% |

## 信号逻辑

**两个条件同时满足才触发：**

1. **季节性窗口**（第二张表）：当前日期在历史统计的最优建仓时间窗口内
2. **市场状态匹配**（第一张表）：
   - STATE 1 窄幅震荡（ADX<20）→ 不入场
   - STATE 2 趋势启动（布林带开口+突破）→ 可入场
   - STATE 3 缓慢趋势（ADX>25+EMA交叉）→ 最佳入场
   - STATE 4 极端行情（BIAS>5%或RSI>80）→ 不入场

## 配置飞书推送（可选）

1. 在飞书群创建自定义机器人，复制 Webhook URL
2. 进入 GitHub repo → Settings → Secrets → New repository secret
3. Name: `FEISHU_WEBHOOK`，Value: 你的 webhook URL
